Data

    

      
Adjusted daily closing prices from Yahoo Finance, 2 January 2008 to 31 December 2018, for the Dow Jones Industrial Average and six stocks: Intel, IBM, Apple, Microsoft, 3M and Cisco. Each exercise selects the period stated in the book.

      
To run an exercise on your own computer, save bookkit.py, prices.csv and the exercise file in one folder, then run it with Python 3, numpy, scipy and matplotlib.

    

  


  

    
Notes on the code

    

      
The Python follows the book’s MATLAB line by line where it can. Where the printed code has a slip, the Python corrects it and says so in a comment marked NOTE:

      
    
        
  • Returns: the AVaR, CVaR-optimisation and performance exercises use net returns Pt/Pt−1 − 1; the printed code divides prices only, which gives gross returns close to 1.
    • 
        
  • Time series: the book’s estimates imply a negative average DJIA return for 2008–2018, a period in which the index rose, which suggests the price file was read newest first. Here dates run forwards, so the estimates differ.
    • 
        
  • Ten-day VaR: the simulated ten-day return is the sum of the ten daily returns (the printed code keeps only day ten), and Student t draws are rescaled to unit variance, as in the estimated model.
    • 
        
  • Special cases of the stable law: the normal, Cauchy and Lévy densities are S(2, 0, 1/√2, 0), S(1, 0, 1, 0) and S(0.5, 1, 1, 0); the printed parameters do not give these laws.
    • 
        
  • Smaller slips: the normal density’s constant is σ√(2π); QQ plots use plotting positions; the AVaR function called by the code is written out; the performance portfolio holds all six stocks; the Rachev ratio’s boundary term uses index ⌈nα⌉.
    • 
        
  • MATLAB toolbox functions are re-implemented: stable fitting by maximum likelihood on an FFT density, conditional maximum likelihood for ARMA-GARCH, and the varbacktest tests. Results therefore agree closely with MATLAB, but not to the last digit.
    •
