About the book

Heavy Tails and Coherent Risk Measures in Islamic Finance (Islamic Development Bank Institute, Jeddah, 2021; 170 pp.; ISBN 978-603-8306-06-2) is a hands-on introduction to heavy-tailed distributions and coherent risk measures, written for academics, practitioners and students of Islamic finance.

Financial returns make extreme moves far more often than the normal distribution allows. The book shows how stable laws, copulas and coherent measures such as Average Value at Risk capture that tail risk, and how to apply them to Sharia-compliant portfolios through worked examples.

It is organised in four parts:

  1. An overview of Islamic finance: its sources, core principles and guidelines.
  2. Probability theory, time series modelling, heavy-tailed and stable distributions, and dependence structures.
  3. Applying these methods to risk management, with an emphasis on market risk.
  4. Portfolio selection and optimisation, and performance measurement.

Stable densities Free sample

The exercise

          
The probability density function of an α-stable random variable X has no closed form in general. Its characteristic function is:
E[eiuX] = exp(iμu − |σu|α (1 − iβ sign(u) tan(πα/2))),  α ≠ 1
E[eiuX] = exp(iμu − σ|u| (1 + iβ (2/π) sign(u) ln|u|)),  α = 1
  1. Compare the pdfs of stable distributions for different α values. In each case β = 0.5, γ = 0.8, δ = 0.2.
  2. Compare the pdfs of stable distributions for different β values. In each case α = 0.3, γ = 0.8, δ = 0.2.
  3. Compare the cdfs of stable distributions for different α values. In each case β = 0.5, γ = 0.8, δ = 0.2.
  4. Compare the cdfs of stable distributions for different β values. In each case α = 0.3, γ = 0.8, δ = 0.2.

Compare the pdfs of the standard normal, Cauchy and Lévy distributions, each created as a stable distribution object.

Copulas

            
Gaussian, Clayton, Gumbel and Frank copulas: distribution functions, densities and simulated samples, including Gamma margins.

          

        

        

          
The exercise

          
Consider the following copulas:
  • Gaussian: C(u, v) = Φρ(Φ−1(u), Φ−1(v)), with ρ the linear correlation
  • Student’s t: C(u, v) = tρ,d(td−1(u), td−1(v)), with ρ the linear correlation and d > 2 degrees of freedom
  • Gumbel: C(u, v) = exp{−[(−ln u)θ + (−ln v)θ]1/θ},  θ ≥ 1
  • Clayton: C(u, v) = (u−θ + v−θ − 1)−1/θ,  θ > 0
  • Frank: C(u, v) = −(1/θ) ln[1 + (e−θu − 1)(e−θv − 1)/(e−θ − 1)],  θ ≠ 0
  1. Plot the pdf and cdf of the given copulas.
  2. Generate 1,000 random vectors for the Gaussian copula with ρ = 0.6 and the Clayton copula with θ = 8.
  3. With Gamma margins, f(x) = xα−1 e−x/β / (βα Γ(α)),  x > 0, generate 1,000 random vectors for the Gaussian copula with ρ = 0.6 and the Gumbel copula with θ = 2, both with α = 3, β = 1.

Data

    

      
Adjusted daily closing prices from Yahoo Finance, 2 January 2008 to 31 December 2018, for the Dow Jones Industrial Average and six stocks: Intel, IBM, Apple, Microsoft, 3M and Cisco. Each exercise selects the period stated in the book.

      
To run an exercise on your own computer, unlock the code, then save bookkit.py, prices.csv and the exercise file in one folder, then run it with Python 3, numpy, scipy and matplotlib.

      
These stocks and the DJIA serve as statistical teaching data. They are not screened for Sharia compliance, and the DJIA is not an Islamic benchmark. To apply the methods to a Sharia-compliant portfolio, first screen the universe with a stated rule (for example the AAOIFI standard) at stated dates, and measure performance against an Islamic index.

      
File facts: 2,769 trading days from 2 January 2008 to 31 December 2018, eight series (DJIA and the six stocks), no missing values. Prices are Yahoo Finance adjusted closes, which correct for splits and dividends; the file was extracted once and is fixed, so every run gives the same results. Notes on the code

    

      
The Python follows the book’s MATLAB line by line where it can. Where the printed code has a slip, the Python corrects it and says so in a comment marked NOTE:

      
    
        
  • Returns: the AVaR, CVaR-optimisation and performance exercises use net returns Pt/Pt−1 − 1; the printed code divides prices only, which gives gross returns close to 1.
    • 
        
  • Time series: the book’s estimates imply a negative average DJIA return for 2008–2018, a period in which the index rose, which suggests the price file was read newest first. Here dates run forwards, so the estimates differ.
    • 
        
  • Ten-day VaR: the simulated ten-day return is the sum of the ten daily returns (the printed code keeps only day ten), and Student t draws are rescaled to unit variance, as in the estimated model.
    • 
        
  • Special cases of the stable law: the normal, Cauchy and Lévy densities are S(2, 0, 1/√2, 0), S(1, 0, 1, 0) and S(0.5, 1, 1, 0); the printed parameters do not give these laws.
    • 
        
  • Smaller slips: the normal density’s constant is σ√(2π); QQ plots use plotting positions; the AVaR function called by the code is written out; the performance portfolio holds all six stocks; the Rachev ratio’s boundary term uses index ⌈nα⌉.
    • 
        
  • MATLAB toolbox functions are re-implemented: stable fitting by maximum likelihood on an FFT density, conditional maximum likelihood for ARMA-GARCH, and the varbacktest tests. Results therefore agree closely with MATLAB, but not to the last digit.
    • 
        
  • Exercise 12: the book computes its “Sharpe” ratio with the DJIA in place of a risk-free asset, which makes it neither a classic Sharpe ratio nor an information ratio. It is kept and labelled as the book’s ratio, and the information ratio (active return over tracking error) is shown beside it. A classic Sharpe ratio would need a risk-free series, which the data file does not include.
    • 
        
  • Fitted-distribution tests: when parameters are estimated from the same data, the standard Kolmogorov–Smirnov table overstates the p-value. Exercise 4 adds the Lilliefors version, and exercise 7 adds a parametric bootstrap for the stable fit. With the bootstrap, the stable law is rejected at 5% (p ≤ 0.01: the observed statistic is larger than all 99 bootstrap statistics) although the standard table did not reject it (p = 0.059). Its tails are also too heavy for this sample: its 99% VaR is 5.0% against an empirical 3.7%, and losses beyond it occurred on 0.36% of days instead of 1%.
    • 
        
  • Added diagnostics, beyond the book: residual tests (exercise 3), tail dependence coefficients (exercise 6), GARCH persistence and Monte Carlo intervals (exercise 8), a legend for the backtest traffic lights (exercise 10) and a note on the corner solution of the optimiser (exercise 11).
