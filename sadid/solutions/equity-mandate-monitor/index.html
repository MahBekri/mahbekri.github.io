Equity Mandate Monitor

Is each external manager running the mandate within the limits agreed, and which findings need escalation?

Prototype: the functions below exist and run on synthetic data. The workbook has not been independently validated and is not on sale. What the status labels mean.

Scope

What it does, and what it does not.

  • Compares up to three managers with one benchmark on return, volatility, realised tracking error, information ratio, beta and drawdown.
  • Reports a historical tail average and normal-model expected shortfall, with the number of observations behind the historical figure.
  • Reports the largest single weight, the weight of the five largest holdings, the effective number of names and an approximate active share.
  • Compares each holding with three financial-ratio thresholds the user enters, and classifies it as PASS, ABOVE, MISSING or INVALID.
  • Gives a status for three controls: tracking error, single-name concentration and screening thresholds. Missing or invalid data shows as INCOMPLETE, never as a pass and never as a confirmed breach.

It is an oversight tool, not a portfolio-selection tool and not a screening-data service. The screening test uses three financial ratios supplied by the user. It has no business-activity screen and no purification calculation, and it is not a Sharia compliance determination. The overall status is not a full mandate compliance opinion.

Inputs

What you enter.

Limits and thresholds

Tracking-error limit and watch level, single-name limit, three screening thresholds, the confidence level, and the name and version of the screening methodology adopted.

Returns

120 monthly returns for the benchmark and each manager.

Holdings

For each manager: weights, benchmark weights and three screening ratios per holding, already computed on the methodology's own denominator.

Method

How each figure is calculated.

Tracking error = standard deviation of monthly active returns x sqrt(12) Information ratio = annualised arithmetic mean active return / tracking error Maximum drawdown = lowest value of index / running peak - 1, with the index starting at 1 Historical VaR = - (interpolated lower-tail quantile of monthly returns) Historical tail avg = - (mean of monthly returns at or below that quantile) Tail ratio = historical tail average / normal-model ES, when both are positive Effective names = 1 / sum of squared weights Active share = half the sum of absolute active weights (approximate)

Losses are shown as positive numbers. The historical tail average is a threshold-average approximation of expected shortfall. Active share is approximate, because benchmark names not held are grouped into one line, and should not be used as an exact mandate control.

Status rules. A control shows BREACH only when the data behind that control is complete and valid. If returns, holdings or inputs fail a data check, the affected control shows INCOMPLETE, whatever the numbers say. For screening thresholds there is one more state: when holdings are above an entered threshold but no adopted methodology is recorded, the status is PROVISIONAL. It becomes BREACH once an adopted methodology and its version are entered. None of these is a Sharia screening determination, which needs an adopted methodology, its own denominators, a business-activity screen and an authorised reviewer.

Changing thresholds alone does not reproduce a published methodology: ratios must be entered on that methodology's denominator, for example total assets or average market capitalisation.

Limitations

When not to rely on it.

  • Tracking error is realised, not predicted. A risk model is needed for a forward-looking figure.
  • With 120 monthly observations, a 97.5% historical tail rests on three or four data points.
  • Active share is approximate because benchmark names not held are grouped into one line.
  • The sample holds 12 lines per manager and 120 months. Other sizes need the formulas extended.
  • Screening uses three financial ratios only, with no business-activity screen and no purification.
