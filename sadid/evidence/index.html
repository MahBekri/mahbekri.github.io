How to run it

Download the files into one folder and run the script with Python. It needs numpy and scipy.

python3 reference_checks.py

It prints one line per output, with the recomputed value, the workbook value and PASS or FAIL, and ends with a count. The tolerance is an absolute difference of 0.000001 on every value.

What this does and does not show

  • It shows that the workbook formulas and a separately written calculation give the same numbers on one synthetic case per model.
  • Both were written by the same author from the same specification. It is a cross-check, not an independent validation.
  • The input-control tests cover 37 chosen cases of blank, text, negative, out-of-range and inconsistent inputs. They are not exhaustive.
  • The Microsoft Excel test is recorded on the validation page. Its reports are not among these files.
  • Nothing here shows whether the method suits any institution.
  • The workbooks themselves are not published here. They are prototypes and not on release.

All data is synthetic. No real institution, portfolio, security or market is represented.
