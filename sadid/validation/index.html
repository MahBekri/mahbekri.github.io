How a reference example is checked

Two calculations that must agree.

Each workbook is built from formulas only and recalculated in full. A second calculation is then written in Python from the written method, not from the workbook formulas, and run on the same synthetic inputs. The model passes this check only when the two sets of outputs agree.

This can detect range, sign and implementation errors that the reference case happens to exercise. It does not establish that every formula is correct: one matching example leaves other paths untested, and both calculations were written by the same author from the same specification, so they can share a mistaken assumption. It also does not show that the method is right for a given institution, that the inputs are good, or that the workbook behaves correctly on data unlike the sample.

The latest run, on 19 November 2026, compared 117 outputs across the four models with an absolute tolerance of 0.000001, using Python 3.13, numpy 2.5 and scipy 1.18. All 117 agreed. The inputs, the workbook outputs and the script are published as evidence files.

Known open issues

What stands between prototype and the next label.

  • None of the workbooks has been opened and recalculated in Microsoft Excel. They were built and recalculated in LibreOffice, and the sample dashboards are LibreOffice renderings.
  • No independent human reviewer has examined any model.
  • Invalid and extreme inputs have been tested systematically only in part, and only for the Equity Mandate Monitor.
  • No model has been reviewed by a Sharia scholar or board. No model issues a Sharia determination.
  • All examples use synthetic data. No model has been run on an institution's data.
  • No tests yet of numerical stability, tolerance sensitivity, zero or negative rates, other spreadsheet versions, or whether a release can be rebuilt identically.
  • The status labels do not yet have written acceptance criteria or a named sign-off for moving from one label to the next.
  • No accessibility test against WCAG has been completed, and the site makes no accessibility conformance claim.
  • Scenario parameters and thresholds in the samples are illustrative and are not calibrated.
